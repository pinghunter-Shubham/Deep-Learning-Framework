📚 How MiniTorch Works — Under the Hood

💾
Storage

The raw 1-D memory buffer. Every tensor — regardless of shape — lives in a flat numpy array here. Reshape & transpose never copy data, they only change how the buffer is interpreted. 

# minitorch/storage.py
self.data = np.ascontiguousarray(data).flatten()
# All tensor data → one flat buffer
📐
Tensor

A view over Storage defined by shape, strides, and offset. Two tensors can share the same storage — a transpose is free. 

# minitorch/tensor.py
view = as_strided(
  storage[offset:],
  shape=self.shape,
  strides=byte_strides   # per dim
)
🔄
Autograd

Every op records itself in a computation graph (_creator, _prev). .backward() topologically sorts the graph and calls each op's backward() in reverse. 

# minitorch/autograd.py
for node in reversed(topo):
    grads = node._creator.backward(
        node._ctx, node.grad)
    for p, g in zip(node._prev, grads):
        p.grad += unbroadcast(g, p.shape)
⚡
Ops & Chain Rule

Each operation (Add, MatMul, ReLU, Conv2d …) is a Function subclass. forward computes the result; backward applies the chain rule to pass gradients back. 

# minitorch/ops.py — ReLU example
class ReLU(Function):
  def forward(ctx, a):
    ctx.save_for_backward(a.data)
    return Tensor(np.maximum(a.data, 0))
  def backward(ctx, grad):
    a, = ctx.saved_tensors
    return grad * (a > 0)   # mask
🧩
nn.Module

Any layer subclasses Module. __setattr__ auto-registers Parameters and child modules so .parameters() collects every weight in the network recursively. 

# minitorch/nn/module.py
def parameters(self):
    params = list(self._parameters.values())
    for m in self._modules.values():
        params.extend(m.parameters())
    return params   # all weights, deep
🎯
Optimizers

After .backward() fills every .grad, the optimizer reads them and updates weights. Adam tracks first and second moment estimates for adaptive step sizes. 

# Adam update (minitorch/optim/adam.py)
m = β1*m + (1-β1)*grad        # mean
v = β2*v + (1-β2)*grad²       # variance
m̂ = m / (1 - β1^t)           # bias-correct
w -= lr * m̂ / (√v̂ + ε)      # step
